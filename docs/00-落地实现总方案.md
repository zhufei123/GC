## 2. 本地一键联调

前置：JDK 21、Maven 3.8+、Node 20+、pnpm、MySQL、Redis。

```bash
# 1) 库（仅首次）
mysql -h127.0.0.1 -uroot -p'recycle@Root123' -e "CREATE DATABASE IF NOT EXISTS recycle DEFAULT CHARSET utf8mb4;"
mysql -h127.0.0.1 -urecycle -p'recycle@Dev123' recycle < backend/sql/01-schema.sql
mysql -h127.0.0.1 -urecycle -p'recycle@Dev123' recycle < backend/sql/02-seed.sql

# 2) 后端
cd backend && mvn -q -DskipTests package
java -jar recycle-admin-api/target/backend.jar
# http://127.0.0.1:8080  health / doc.html

# 3) 管理后台
cd admin-web && pnpm install && pnpm dev
# http://127.0.0.1:5173  代理 /api → 8080

# 4) C/B 端 H5
cd app-uni && pnpm install && pnpm run dev:h5
# http://127.0.0.1:5174
```

无 Docker 时用本机 MySQL 8.0 + Redis 7 即可（与 `application-local.yml` 一致）。有 Docker 时：`docker compose -f deploy/docker-compose.local.yml up -d`（需给 Redis 配密码并同步改 yml）。

鉴权：请求头 `Authorization: {token}`，**无 Bearer**。响应 `{ code, msg, data, ts }`，`code=0` 成功。

1. 后台登录 → 动态菜单 → 分类/SKU/调价（C 端查价即时可见）
