### 1.3 动态路由(必须按此实现)

静态路由仅 `/login`、`/404`、Layout 空壳(`children: []`)。

```ts
const viewModules = import.meta.glob('@/views/**/*.vue')

function menuToRoute(menu: MenuVO): RouteRecordRaw {
  return {
    path: menu.path,
    name: menu.name,
    component: menu.component
      ? viewModules[`/src/views/${menu.component}.vue`]
      : undefined,
    meta: { title: menu.title, icon: menu.icon, hidden: menu.visible === false },
    children: (menu.children ?? []).map(menuToRoute)
  }
}
```

守卫:无 token → 白名单或 `/login?redirect=`;已登录首次拉 `GET /admin-api/auth/me` + `GET /admin-api/auth/menus`(或后端合并为 info);`addRoute('Layout', r)`;**最后**注册 404 通配;然后 `return { ...to, replace: true }` 避免刷新 404。

按钮:`v-permission="'recycle:category:add'"`;超管 perms 含 `*:*:*`。

axios:`baseURL = import.meta.env.VITE_API_BASE_URL`;请求头 `Authorization = token`(无 Bearer);`code===0` 解包 data;`40100/401` 清态跳登录(防抖)。开发 proxy:`/api` → `http://localhost:8080`,rewrite 去掉 `/api` 前缀。

退出:清 token、permission reset、`location.reload()` 骨架可接受。

### 2.3 双角色 tabBar

原生 tabBar 不能运行时整套替换;`custom-tab-bar` 仅微信。定稿:**角色壳页 + 组件化 tab + wd-tabbar**。

C 端 tab:首页 / 查价 / 订单 / 我的。B 端:工作台 / 接单大厅 / 订单 / 门店(或我的含门店入口,与 docs/01 B 端 tab 对齐为工作台/大厅/订单/门店)。

壳内 `v-show` 四个业务组件;`onShow` 分发 `refresh()`;长列表用 `scroll-view`。登录成功 `uni.reLaunch` 到对应壳页。

备选:每 tab 独立页 + 每页挂 tabbar 组件(切 tab 会重建,仅作性能降级)。

### 2.4 请求封装

```ts
uni.request({
  url: BASE_URL + opts.url,
  header: {
    'Content-Type': 'application/json',
    ...(token ? { Authorization: token } : {})
  }
})
```

- H5 开发态 base 走 `/api` proxy;小程序用局域网 IP,不能用 localhost。
- `code===0` 成功;`40100` 清态 + 防抖 `reLaunch` 登录页。
- `uploadFile` 的 `res.data` 需 `JSON.parse`;优先走 COS 直传(签名接口),失败再降级服务端中转。

### 2.6 登录(条件编译)

- 微信:`uni.login` → `POST /app-api/auth/wx-login`;手机号 `open-type=getPhoneNumber` → `bind-phone`
- 支付宝:同理 `alipay-login` + `getAuthorize`
- H5/App:手机号 + 验证码,骨架验证码 123456

分发:

```ts
if (!token) reLaunch login
else if (role === 'recycler' && recyclerStatus === 'approved') reLaunch pages-recycler/index
else reLaunch pages-customer/index
```

P0 不实现「切回客户端」。C 端「我是回收站老板」:未申请 → apply;pending/rejected → result;approved → 下次登录即为 B 端壳(角色已升级)。

### 2.7 拦截器

白名单:launch、login。访问 `pages-recycler/` 非 apply 页时:无申请 → apply;非 approved → result。后端 `/app-api/boss/**` 同样校验,前端只是体验层。

### 2.8 定位与图片

坐标系 gcj02。H5 骨架可不配地图 key,附近站降级纯列表。选图 `compressed` → >500KB 再 `compressImage` / H5 canvas → COS 直传或 `/upload`。订单/称重 1–6 张,串行上传。
