# 04 部署上线指南

> 架构:腾讯云轻量 4核8G(Ubuntu 24.04)上以 Docker Compose 跑 `mysql/redis/backend`,Nginx 装在宿主机负责 `h5/admin` 静态站点、`api` 反向代理与 HTTPS;图片走腾讯云 COS;证书用 acme.sh 自动签发续期。
>
> 域名规划(以 `example.com` 代指):`h5.example.com`(H5)、`admin.example.com`(管理后台)、`api.example.com`(接口)、`cdn.example.com`(COS 加速,可选 CNAME 到 COS 域名)。
>
> 仓库内对应文件:
> - `deploy/docker-compose.local.yml`
> - `deploy/docker-compose.prod.yml`
> - `deploy/.env.example`
> - `deploy/nginx/recycle.conf`
> - `deploy/backup-mysql.sh`
> - `deploy/deploy.sh`
> - `backend/Dockerfile`(后端工程初始化时同步落地)

## 二、生产编排要点

完整 YAML 见 `deploy/docker-compose.prod.yml` 与 `deploy/.env.example`。要点:

- MySQL 仅绑定 `127.0.0.1:3306`;Redis **不映射**任何宿主端口。
- Backend 仅绑定 `127.0.0.1:8080`,由宿主机 Nginx 反代。
- 密码全部来自 `deploy/.env`(不入 git,权限 `chmod 600`)。
- 后端镜像基于 `eclipse-temurin:21-jre-jammy`,健康检查走 `/actuator/health`。
- 生产 Nginx 屏蔽 `/doc.html`、`/swagger`、`/v3/api-docs`、`/actuator`。

## 三、Nginx / HTTPS / 备份 / 发布

完整配置与脚本已落在:

| 文件 | 作用 |
| --- | --- |
| `deploy/nginx/recycle.conf` | h5 / admin 静态站 + api 反代 + gzip + HTTPS + SPA 回退 |
| `deploy/backup-mysql.sh` | 每日 mysqldump,日备份保留 7 天,周日归档保留 35 天 |
| `deploy/deploy.sh` | 本地构建并发布 backend / h5 / admin |

### 3.1 acme.sh 签发与自动续期

用腾讯云 API 做 DNS 验证,一次签发主域 + 泛域名(免费证书 90 天,acme.sh 约每 60 天自动续):

```bash
curl https://get.acme.sh | sh -s email=you@example.com
source ~/.bashrc
export Tencent_SecretId="你的SecretId"
export Tencent_SecretKey="你的SecretKey"
acme.sh --set-default-ca --server letsencrypt
acme.sh --issue --dns dns_tencent -d example.com -d '*.example.com'
mkdir -p /etc/nginx/ssl
acme.sh --install-cert -d example.com \
  --key-file /etc/nginx/ssl/example.com.key \
  --fullchain-file /etc/nginx/ssl/example.com.fullchain.pem \
  --reloadcmd "nginx -s reload"
```

子账号 CAM 仅授予 `QcloudDNSPodFullAccess`。不想给 DNS API 权限时改 webroot(不支持泛域名,需逐个子域签发)。

启用备份:

```bash
chmod +x /opt/recycle/deploy/backup-mysql.sh
( crontab -l 2>/dev/null; echo "30 3 * * * /opt/recycle/deploy/backup-mysql.sh >> /data/backup/backup.log 2>&1" ) | crontab -
/opt/recycle/deploy/backup-mysql.sh   # 手动跑一次
```

恢复演练(务必至少做一次):

```bash
gunzip -c /data/backup/mysql/daily/recycle_XXXX.sql.gz \
  | docker exec -i recycle-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" recycle
```

发布:

```bash
./deploy/deploy.sh all       # 后端 + H5 + 管理后台
./deploy/deploy.sh backend
./deploy/deploy.sh h5
./deploy/deploy.sh admin
```

## 四、从买服务器到上线:逐步 Checklist

- [ ] **1. 购买与初始化**:腾讯云轻量 4核8G、Ubuntu 24.04、包年;控制台重置 root 密码;本地 `ssh-copy-id root@IP` 上传公钥。
- [ ] **2. 系统基线**:`apt update && apt upgrade -y && timedatectl set-timezone Asia/Shanghai`;创建目录 `mkdir -p /opt/recycle/{deploy,backend/target} /var/www/{h5,admin,acme} /data/{mysql,redis,backup,logs}`。
- [ ] **3. 安装 Docker + Nginx**:`curl -fsSL https://get.docker.com | sh && apt install -y nginx`。
- [ ] **4. 防火墙**:腾讯云控制台防火墙只放行 22/80/443;服务器内 `ufw allow 22,80,443/tcp && ufw enable`;SSH 关闭密码登录。
- [ ] **5. 上传部署文件**:把 `deploy/` 目录 scp 到 `/opt/recycle/deploy/`;`cp .env.example .env` 并把所有密码换成强随机值(`openssl rand -base64 24`)。
- [ ] **6. DNS 解析**(需 ICP 备案已通过):DNSPod 添加 A 记录 `h5`、`admin`、`api` → 服务器公网 IP;`cdn` 按 COS 加速指引 CNAME(可选)。
- [ ] **7. 签发证书**:按 acme.sh 步骤签发并安装,`nginx -t` 通过。
- [ ] **8. 启动服务**:`cd /opt/recycle/deploy && docker compose -f docker-compose.prod.yml up -d`;`docker compose ps` 三个服务 healthy。
- [ ] **9. 配置 Nginx**:复制 `recycle.conf` 到 `/etc/nginx/conf.d/`,`nginx -t && systemctl reload nginx`。
- [ ] **10. 首次发布**:本地执行 `./deploy/deploy.sh all`;浏览器验证 `https://h5.example.com`、`https://admin.example.com`;内网 `curl 127.0.0.1:8080/actuator/health` 返回 UP,外网 `/actuator` 返回 404。
- [ ] **11. 备份与监控**:启用备份 crontab 并手动跑一次;做一次恢复演练;开启腾讯云轻量的自动快照(每日)。
- [ ] **12. 合规收尾**:H5/后台页脚挂 ICP 备案号;30 日内提交公安备案;微信/支付宝小程序后台配置 `https://api.example.com` 为合法域名。
- [ ] **13. 上线验收**:注册登录 → 查价 → 下单 → 老板接单 → 称重完成;管理后台改价后 C 端可见。

## 五、安全清单

| 项 | 措施 |
|----|------|
| 防火墙 | 云防火墙 + ufw 双层,仅开 22/80/443;3306/6379/8080 一律不对公网开放 |
| SSH | 仅密钥登录:`PasswordAuthentication no`、`PermitRootLogin prohibit-password`;可选 fail2ban |
| 弱密码 | `.env` 中所有密码用 `openssl rand -base64 24` 生成;`.env` 权限 `chmod 600` 且不进 git |
| Redis | 不映射宿主端口、`requirepass`、禁用 `FLUSHALL/CONFIG` |
| MySQL | 仅绑定 127.0.0.1;应用使用低权限账号 `recycle`;远程访问走 SSH 隧道 |
| Token | `JWT_SECRET`/`sa-token` 密钥 ≥64 位随机;App 端 7 天滑动续期,管理后台 2 小时;登出踢旧 token |
| CORS | 后端只允许 `https://h5.example.com`、`https://admin.example.com`,禁止 `*` |
| 接口 | 生产屏蔽 Knife4j 与 actuator 外网访问;上传校验类型与大小;登录/验证码限流 |
| 数据 | 每日备份 + 每周归档 + 恢复演练;COS 桶私有读,图片走临时 URL 或 CDN 鉴权 |

## 六、发布路径

**H5**:`pnpm build:h5` → `deploy.sh h5` 同步到 `/var/www/h5` → 即时生效,无审核。

**微信小程序提审**:

1. 公众平台 → 开发设置 → request 合法域名添加 `https://api.example.com`。
2. `pnpm build:mp-weixin`,用微信开发者工具打开 `dist/build/mp-weixin`。
3. 上传 → 体验版真机回归 → 提交审核(类目:生活服务>废品回收)。
4. 常见驳回:类目资质不符、页面空数据、诱导分享文案。

**支付宝小程序**:`pnpm build:mp-alipay` → 开发者工具上传 → 开放平台提审。

**App(HBuilderX 云打包)**:

1. `manifest.json` 配置 AppID、包名(与 App 备案一致)、版本号、图标启动图。
2. 安卓:自有证书云打包 → APK/AAB → 各商店提审(需软著 + ICP/App 备案号 + 隐私政策 URL)。
3. iOS:Bundle ID 与发布证书 → 云打包 ipa → Transporter → App Store Connect。
4. 发版顺序:后端(兼容旧版)→ H5 → 小程序提审 → App 商店提审。
